Почему СОЮЗ

Инфраструктура, а не обёртка

Production-grade ядро: durable state, честный биллинг и маршрутизация, которой можно доверять.

01

Waterfall-маршрутизация

Canonical-модели поверх provider variants. Падает провайдер — запрос переезжает на следующий по health и цене.

02

Durable по умолчанию

Postgres — canonical state, Postgres-backed очереди. Генерация, оплата и доставка вебхука не теряются при рестарте.

03

Все модальности

Изображения, видео, аудио и текст через единый async-контракт. Длинные задачи — всегда асинхронно.

04

Честный биллинг

Append-only ledger, saga/outbox. Кредиты списываются строго по факту — без потерь и задвоений.

05

Multi-tenancy

Изоляция по customer_id (B2B) и user_id (B2C), RLS на core-таблицах. Масштабируется на тысячи клиентов.

06

Stateless и быстрый

API валидирует, ставит job в очередь и возвращает 202. Воркеры делают тяжёлую работу. Идемпотентность из коробки.

Интеграция за минуты

Знакомый REST, предсказуемые ошибки, async с вебхуками. Никаких сюрпризов в продакшене.

app.ts
// клиент
const souz = createClient({ apiKey: process.env.SOUZ_KEY });

// создаём генерацию — возвращается сразу
const job = await souz.generations.create({
  model:  "video.kling-v2",
  prompt: "кот-космонавт чинит спутник",
});

// результат — вебхуком или поллингом
const result = await souz.generations.wait(job.id);
console.log(result.assets[0].url);
