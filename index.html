Почему Souz

Инфраструктура, а не просто обёртка

Не очередной прокси к одной модели. Souz — production-grade ядро: durable state, честный биллинг и маршрутизация, которой можно доверять.

🔀

Waterfall-маршрутизация

Canonical-модели поверх provider variants. Падает один провайдер — запрос переезжает на следующий по health и цене. Без переписывания кода.

🛡️

Durable по умолчанию

Postgres — canonical state, Postgres-backed очереди для задач. Ни одна генерация, оплата или доставка вебхука не теряется при рестарте.

🎨

Все модальности

Изображения, видео, аудио и текст через единый async-контракт. Длинные задачи — всегда асинхронно, с прогрессом и вебхуками.

💳

Честный биллинг

Append-only ledger, saga/outbox. Кредиты списываются строго по факту, никаких потерянных или задвоенных платежей.

🔑

Multi-tenancy с первого дня

Изоляция по customer_id (B2B) и user_id (B2C), RLS на core-таблицах. Безопасно масштабируется на тысячи клиентов.

⚡

Stateless и быстрый

API только валидирует, кладёт job в очередь и возвращает 202. Воркеры делают тяжёлую работу. Идемпотентность из коробки.

Интеграция за минуты

Знакомый REST, предсказуемые ошибки, async с вебхуками. Никаких сюрпризов в продакшене.

const souz = createClient({ apiKey: process.env.SOUZ_KEY });

// создаём генерацию — возвращается сразу
const job = await souz.generations.create({
  model: "video.kling-v2",
  prompt: "кот-космонавт чинит спутник",
});

// получаем результат вебхуком или поллингом
const result = await souz.generations.wait(job.id);
console.log(result.assets[0].url);
